Import a PNB statement

  1. PNB One → Account Services → Download Statement → choose Excel.
  2. Pick up to 3 months per file: PNB One stops at 500 transactions and silently drops older rows. For a year, download 4 files. Overlaps are fine.
  3. Drop the file here. It is password-protected; the password is usually your full account number. Decryption happens on this device.
